# 3D Model Directory

Place your custom 3D model here:
- Recommended path: `/models/product.glb` (or `.gltf`)
- File format: Binary GLTF (.glb) or Standard GLTF (.gltf)

The Proto3D application automatically checks for `/models/product.glb`.
If no custom file is found or while loading, Proto3D smoothly displays the precision-engineered Proto X1 spatial audio architecture.
You can also drag-and-drop or select any `.glb` model directly using the model picker in the application controls!
